# SSLScout domain list
#
# One entry per line. "#" starts a comment (whole line or trailing), blank
# lines are ignored and duplicates are dropped while the original order is
# preserved.
#
# Accepted formats:
#   domain                     -> port 443
#   domain:port                -> explicit port (e.g. smtp.example.com:465)
#   https://domain/path        -> host and port are taken from the URL
#   smtp://domain              -> STARTTLS: the certificate only shows up after
#                                 the plaintext protocol agrees to upgrade
#
# Schemes that negotiate: smtp (587), imap (143), pop3 (110), ldap (389),
# postgres (5432). The port alone is enough for those five defaults; the scheme
# is how you say it on a non-standard port. "tls://host:port" forces a direct
# handshake when the guess would be wrong.
#
# Commented examples:
#   smtp.example.com:465       # SMTP over implicit TLS
#   smtp.example.com:587       # SMTP over STARTTLS (inferred from the port)
#   smtp://relay.example.com:2525
#   imap://mail.example.com    # IMAP + STARTTLS on 143
#   ldap://ldap.example.com    # LDAP + StartTLS on 389
#   postgres://db.example.com  # PostgreSQL SSLRequest on 5432
#   https://api.example.com/v1 # the path is ignored, host:port is what counts
#   ldap.example.com:636       # LDAPS: implicit TLS, no negotiation
